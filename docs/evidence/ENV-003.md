# ENV-003：Windows 首次啟動隔離驗證

日期：2026-11-11。狀態：PASS（離線 wheel、線上模型權重）。
對應 T039、R012、A013。

## 環境與來源

Windows x64、Python 3.13.17、RTX 2070 SUPER。將目前專案程式、啟動檔與套件鎖定檔放入獨立暫存目錄，套件來源為專案離線 wheel 備份。開始時沒有虛擬環境、權重、資料庫或自訂設定。權重來源為 Demucs 官方下載位置。

## 執行

由 CMD 執行 `Start Music Stem Lab.cmd --no-browser`。第一次輸入 N，確認退出且沒有建立 `.venv`。第二次輸入 Y，等待建置和服務啟動，以隔離的資料目錄驗證 `/api/hardware` 可同時讀取 GPU 與 RAM。

## 結果

虛擬環境成功建立。套件由離線 wheel 安裝。模型下載從 75% 更新至 94%，接著通過 SHA-256 與 CUDA 運算檢查，顯示 100% 並啟動服務。硬體端點回傳 GPU 與 RAM。

從零線上取得所有 Python 套件及 WinGet 安裝 Python 為 NOT_RUN。模型音質比較見 LOCAL-MODEL-003 的驗證範圍。
