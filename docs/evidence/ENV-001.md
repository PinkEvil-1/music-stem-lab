## 判讀與下一步

1. 本機可作為 CPU 推論的候選驗證環境；能否載入選定模型、速度及記憶體峰值仍須測試。
2. GPU 只有 2 GiB，且盤點時可用約 802 MiB，不能預設可跑預設模型。Demucs 上游記憶體說明及低記憶體設定只供參考，不是本機測試結果。[S001]
3. 暫以 CPU 路徑建立可重現 baseline 為建議，不因此永久放棄 GPU；若測試 GPU，先核對權重、PyTorch wheel、GPU 架構、驅動及記憶體，不能只看到 NVIDIA 型號就宣稱支援。
4. 現有 Python 3.13 不等於整套分離依賴皆相容；先解析候選版本的完整依賴，再選 interpreter 與隔離環境。不要直接在全域 Python 安裝實驗套件。[S006]
5. FFmpeg／ffprobe 需要加入本專案可重現的工具方案；PATH 找不到與整台電腦未安裝不同。
6. 磁碟空間是單次快照，目前沒有從容量直接推導可排隊數；仍需量測單筆來源、分軌、暫存及恢復副本的峰值。
7. T010 完成只代表「盤點完成」，G0 的依賴可重現尚未達成；T011 應先補齊依賴相容性、素材及權重許可證據。

## 切換硬體的影響

| 變更 | 可能影響 | 必須重測 |
| --- | --- | --- |
| CPU 或 CPU ↔ GPU | 執行速度、記憶體、數值運算及套件支援 | 模型載入、固定案例輸出差異、耗時與峰值 |
| VRAM 增減 | 可否使用原分段／batch；是否 OOM | 最大可用參數、OOM 與取消 |
| RAM 或其他程式佔用 | 可用資源、記憶體不足風險 | 載入與完整流程資源峰值 |
| 磁碟容量／裝置 | 空間限制、讀寫速度 | 暫存峰值、配額與發布／恢復 |
| OS、驅動或工具版本 | 安裝相容性、解碼及模型執行 | 環境重建、來源解碼、固定音質回歸 |
| 因資源限制更換模型／segment／精度 | 音質與殘留可能改變 | Q001／Q002／Q005，不只效能 |

模型與參數相同仍不要求跨裝置逐位元一致；品質接受度用固定案例量測與盲聽評估。
換硬體不必改寫產品需求，應新增 ENV 報告與實驗，保存舊結果作比較。

## 重跑盤點的方法

在實際將執行推論的主機查詢以下項目，僅選列必要欄位，不匯出整份系統資訊：

- WMI Win32_OperatingSystem：Caption、Version、BuildNumber、OSArchitecture、TotalVisibleMemorySize、FreePhysicalMemory。
- WMI Win32_Processor：Name、NumberOfCores、NumberOfLogicalProcessors。
- WMI Win32_VideoController：Name、DriverVersion。VRAM 用 nvidia-smi 查詢，不以 WMI AdapterRAM 判斷。
- WMI Win32_LogicalDisk：僅專案所在磁碟的 FileSystem、Size、FreeSpace。

版本與 NVIDIA 顯示記憶體查詢：

~~~powershell
python --version
python -c "import struct; print(struct.calcsize('P') * 8)"
python -c "import importlib.metadata as m; names=['pip','torch','torchaudio','demucs','yt-dlp','fastapi','numpy']; [print(n + ': ' + (m.version(n) if next(m.distributions(name=n), None) else 'NOT_INSTALLED')) for n in names]"
git --version
nvidia-smi --query-gpu=name,driver_version,memory.total,memory.free --format=csv,noheader
nvidia-smi --version
~~~

以 Get-Command 檢查工具是否位於 PATH，避免輸出含個人帳號的安裝路徑。
本次 WMI 沙箱內查詢遇到 AccessDenied，改用已核准的沙箱外唯讀查詢成功；沒有變更系統權限或設定。
