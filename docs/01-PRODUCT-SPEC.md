# 產品需求規格 v0.4

日期：2026-11-09。狀態：部分已實作，模型品質待驗。使用者已指定模型由另一台電腦處理，本機非模型功能先行。實際範圍見 11-REMOTE-WORKER.md 與 06-TASKS.md。

新增 download_audio 獨立模式，必要產物為 source 與 manifest。execution_kind=demo 使用明確標示的合成音，real 才代表真實工作。下列原始目標仍保留，未完成項目不可推定已通過。

## 分軌範圍（D013）

只使用所選模型／權重原生提供的分軌類別及軌數，不另行辨識或拆分同類樂器個體，不固定要求四軌、六軌或其他數量。
選定模型的能力表是輸出契約依據；伴奏是從已提供的類別產生的衍生混音，不算額外原生分軌。
R003 去人聲與 R004 去吉他仍是必要需求，選模時須能提供對應目標類別。若模型沒有 guitar，不能把 other 假稱為 guitar，也不能默默取消去吉他。

## 使用情境

使用者輸入一至多個影片網址，選擇處理模式，提交後可關閉網頁。背景工作依序完成，重新開啟頁面仍可查詢狀態、試聽及下載。去吉他適合練習吉他時保留歌聲與其他伴奏；去人聲適合保留樂器伴奏。

## 處理模式與額外輸出

| mode | 目的 | 必要輸出 |
| --- | --- | --- |
| download_audio | 僅取得來源音訊 | source、manifest |
| separate | 模型原生分軌，並依勾選額外輸出伴奏 | source、模型原生 stems、已勾選的 no_vocals／no_guitar、manifest |

「額外輸出去人聲版本」與「額外輸出去吉他版本」為兩個獨立 checkbox，預設皆不勾；可都不選、單選或雙選。
不論額外選項為何，模型原生分軌全部保留。雙選產生兩個獨立伴奏，不代表同時消除人聲與吉他的一個合併版本。
選項隨工作、重試與 manifest 保存；所選模型需具有對應目標類別，不能用 other 冒充 guitar。
僅下載模式不接受額外伴奏選項。舊 remove_vocals／remove_guitar API 保留相容，但不再作為新網站主要選項。

同一首歌只建立一筆 separate 工作；額外伴奏由同次分軌結果衍生，遠端模型尚未接入前不宣稱已能實際生成。

## 明確不在第一版範圍

公開多租戶、付費、分享連結、播放清單自動展開、直播、私人／付費／登入限定來源、原始錄音室分軌保證、同類樂器逐一獨立分軌、任意樂器指定移除、特定吉他手辨識、訓練專用模型、自動轉譜及即時分離。

## 非功能需求草案

- N001：個人使用，預設僅監聽 loopback。若部署私人伺服器，需限制私人網路存取；暴露遠端前補足身分驗證。
- N002：網頁與後端重啟不遺失已提交工作；狀態及順序保存在資料庫。
- N003：所有推論在受控主機執行，不把音訊上傳第三方分離服務。
- N004：檔名使用系統 ID；標題只用於顯示。下載路徑不得由使用者指定。
- N005：工作完成須同時滿足產物驗證、持久化成功與 manifest 提交。
- N006：不顯示虛構 ETA。無可量測進度時只顯示階段及經過時間。
- N007：模型、權重、依賴版本及參數可追蹤；升版必須回歸固定案例。
- N008：執行速度、GPU 記憶體與磁碟上限以 T010–T015 實測及確認為準，尚無 SLA。

## 建議初始限制，未經確認

單次最多 20 筆；單片最長 20 分鐘；來源檔最多 500 MiB；私人單使用者；首版不自動清除完成檔案。
需要可調整的工作逾時、最大磁碟配額及最低剩餘空間。具體值由環境盤點決定。
這些是提案，不代表目前有程式強制執行。
