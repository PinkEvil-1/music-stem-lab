# 產品需求規格 v0.1

日期：2026-11-09。狀態：草案。使用者明確需求見 R001–R006；其餘為建議細節。

## 使用情境

使用者輸入一至多個影片網址，選擇處理模式，提交後可關閉網頁。背景工作依序完成，重新開啟頁面仍可查詢狀態、試聽及下載。去吉他適合練習吉他時保留歌聲與其他伴奏；去人聲適合保留樂器伴奏。

## 功能需求

| ID | 優先級 | 需求 | 對應驗收 |
| --- | --- | --- | --- |
| R001 | 必要 | 網頁貼上單一或多行 YouTube 網址；每行一筆，逐筆顯示驗證結果 | A001、A002 |
| R002 | 必要 | 背景取得可處理音訊；保留來源資訊與可供使用者下載的音檔 | A003、A011 |
| R003 | 必要 | 去人聲：輸出 vocals 與 no_vocals | A004、Q001 |
| R004 | 必要 | 去吉他：輸出 guitar 與 no_guitar；保留人聲、鼓、bass 及其他非吉他成分 | A005、Q002 |
| R005 | 必要 | 保存來源音訊、分軌、匯出音檔與 manifest；可查詢及下載 | A006、A011 |
| R006 | 必要 | 多筆持久化 FIFO 排隊；同時至多一筆執行完整工作流程 | A007、A008 |
| R007 | 建議必要 | 顯示每筆狀態、目前階段、已知進度、錯誤與輸出列表 | A009 |
| R008 | 建議必要 | 支援取消、失敗重試與程序重啟恢復；失敗不阻擋後續工作 | A008、A010 |
| R009 | 延伸 | 輸出 vocals、drums、bass、guitar、piano、other 等受模型支援的分軌 | A012、Q003 |

| R011 | 建議必要 | 單軌與伴奏可在頁面試聽、下載；整批 ZIP 可列後續 | A011 |
| R012 | 必要 | 需求、分析、任務、驗證、決策及交接可由純文字還原 | A013 |

R004 的「吉他」包含一般木吉他與電吉他；低音吉他獨立歸 bass，預設不移除。夏威夷吉他、烏克麗麗、班鳩、吉他合成音及其他邊界案例暫不承諾，須另建案例。

## 處理模式草案

| mode | 目的 | 必要輸出 |
| --- | --- | --- |
| remove_vocals | 移除全部可辨識歌聲，包含主唱與和聲 | source、vocals、no_vocals、manifest |
| remove_guitar | 移除所有一般吉他；保留歌聲 | source、guitar、no_guitar、manifest |
| multi_stem | 模型支援的多樂器類別 | source、能力表指定的 stems、manifest |

第一版一次工作選一種模式。同一來源的不同模式可各建一筆，不在第一版共享推論快取。
「去人聲兼去吉他」屬後續混音組合，不以連續套用兩個模型作為預設流程。

## 明確不在第一版範圍

公開多租戶、付費、分享連結、播放清單自動展開、直播、私人／付費／登入限定來源、原始錄音室分軌保證、任意樂器指定移除、特定吉他手辨識、訓練專用模型、自動轉譜及即時分離。

## 非功能需求草案

- N001：個人使用，預設僅監聽 loopback。若部署私人伺服器，需限制私人網路存取；暴露遠端前補足身分驗證。
- N002：網頁與後端重啟不遺失已提交工作；狀態及順序保存在資料庫。
- N003：所有推論在受控主機執行，不把音訊上傳第三方分離服務。
- N004：檔名使用系統 ID；標題只用於顯示。下載路徑不得由使用者指定。
- N005：工作完成須同時滿足產物驗證、持久化成功與 manifest 提交。
- N006：不顯示虛構 ETA。無可量測進度時只顯示階段及經過時間。
- N007：模型、權重、依賴版本及參數可追蹤；升版必須回歸固定案例。
- N008：執行速度、GPU 記憶體與磁碟上限以 T010–T015 實測及確認為準，尚無 SLA。

## 建議初始限制，未經確認

單次最多 20 筆；單片最長 20 分鐘；來源檔最多 500 MiB；私人單使用者；首版不自動清除完成檔案。
需要可調整的工作逾時、最大磁碟配額及最低剩餘空間。具體值由環境盤點決定。
這些是提案，不代表目前有程式強制執行。
