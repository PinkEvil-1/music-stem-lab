# 技術驗證與驗收計畫

本機控制面已有測試與真實瀏覽器通過證據，見 evidence/LOCAL-001.md。模型與音質測試仍為 NOT_RUN／DEFERRED。音質門檻是草案，需在正式評選模型前固定。

## 驗證順序與關卡

G0：硬體、OS、磁碟、GPU 與依賴可重現。
G1：有授權與參考軌的素材可解碼，模型／權重／參數與授權已鎖定。
G2：去人聲品質達標。
G3：單吉他及多吉他全部移除品質達標，且保留 bass 與人聲。
G4：處理時間、記憶體、磁碟及失敗行為在實測環境可接受。
G5：模型關卡仍約束真實分軌上線；使用者已指示模型由另一台電腦處理，因此本機網站／控制面不再等待 G0–G4，見 D010。
G6：網站、佇列、取消、恢復與儲存驗收。
G2／G3 是必要品質關卡；若 R004 無可用模型，應回報技術受阻，不把需求自動降級。

## 素材與可重現性

至少 12 組各 30–60 秒的不同片段，涵蓋 C001–C006、C009–C011，含至少 2 組無目標負例；另至少 3 首完整長度音樂測試流程。
C012 用模擬來源錯誤及合法可測來源驗證，不故意繞過受限內容。
同一首的相似片段不算不同測試歌曲。量測用有參考分軌素材；真實混音用盲聽，無參考時不宣稱客觀分離分數。
每筆記錄許可依據、來源 ID、音訊雜湊、混音方法、各原始軌、時段及重取樣規則。
吉他參考 g_ref 為所有目標吉他軌加總；no_guitar_ref 為其餘原始軌加總。bass 明確排除在目標外。
對商業混音的 EQ、壓縮及殘響可能無法由原始 stems 線性重建，不能把未匹配的混音當乾淨 ground truth。

## 量測與門檻草案

使用一致的取樣率、聲道、延遲對齊與評分工具版本；先固定對齊規則，再比較模型。
參考軌情境記錄 SI-SDR／SDR 改善、殘留與非目標損傷，不用單一分數代表所有聽感。
SI-SDR 對接近靜音參考不穩定；無目標負例改用與原混音差異及盲聽。
若用參考投影估計目標衰減，記錄相關性／殘響造成的限制；不能拿總輸出 RMS 下降當作吉他消除。

盲聽採隨機順序及音量匹配，保留原始未匹配檔供削波與增益檢查。
評分建議：
- 目標殘留：0 無可辨識、1 輕微、2 明顯但可練習、3 干擾、4 幾乎未移除。
- 非目標損傷：0 無明顯、1 輕微、2 明顯音色損傷、3 主要成分丟失、4 不可用。
- 必要案例：殘留 ≤ 1、非目標損傷 ≤ 1、使用者判斷可用；任一 C004–C006 不通過均列出，不用平均掩蓋。
- 困難案例單獨報告，與使用者確認是否限縮支援範圍；不得自動改寫需求。

正式採用門檻需使用者確認。單人盲聽能做自用決策，不能宣稱跨聽眾的統計結論。
尚無固定 SI-SDR 數字，因素材、評分定義與 baseline 未確立；T012–T014 先建立數據再固定，不事後移動門檻以讓候選過關。

## 效能與資源

記錄冷啟動／熱啟動、每階段秒數、real-time factor（處理秒數／音訊秒數）、峰值 GPU／RAM、磁碟峰值與最終大小。
同素材同參數至少 3 次，保留個別結果與中位數。實際硬體未知前不提供分鐘數承諾。
測試低磁碟、OOM、程序中止、過長來源、外部工具掛住及取消。
多筆順序測試用至少 3 筆，確認完整流程不重疊。
