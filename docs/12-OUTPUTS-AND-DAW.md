# 分軌輸出與 DAW 使用方式

日期：2026-11-09。對應 R005 保存檔案、R009 模型原生分軌、R011 試聽與下載。
性質：現有規格的說明，不新增 DAW 專案或 MIDI 匯出需求。

## 會得到什麼

通常會得到多個獨立音訊檔（stems），每個檔案代表模型提供的一個音源類別。
本專案分離輸出的格式為 PCM WAV，可匯入支援 WAV 的 DAW，各放在一條音訊軌上。

以候選 Demucs 六類模型作示意：
- vocals.wav：人聲。
- drums.wav：鼓。
- bass.wav：低音。
- guitar.wav：模型估計的整體吉他類別。
- piano.wav：鋼琴。
- other.wav：其他音源。

這是類別與檔名示意，不是目前已生成的檔案，也不代表最終一定採六軌模型。
實際類別與數量遵循 D013，由所選模型／權重的原生輸出決定。
Demucs 官方說明列出 WAV 分軌及六類模型能力：
https://github.com/facebookresearch/demucs

## 如何放進 DAW

建立 DAW 專案，將各 WAV 匯入不同音訊軌，放在相同時間起點。
分軌應保留共同時基、相同取樣率與長度，不能各自裁掉開頭靜音。
若 DAW 自動啟用音訊伸縮或節拍對齊，應檢查是否改變原本時間關係。

接著可以獨立調整各軌音量、靜音、加效果，或錄製自己的演奏。
例如把 guitar 軌靜音，就能聽其他類別組成的伴奏；多把吉他若都歸在 guitar 類別，會一起靜音。

這些是音訊波形，不是 MIDI 音符，也不會自動變成虛擬樂器或樂譜。
不是自動產生特定 DAW 的專案檔；各 DAW 的專案格式與匯入對話框不同。
若只想播放練習伴奏，不必開 DAW，可以直接使用衍生混音檔。

## 模型輸出與網站產物的差別

模型原生 stems 是各類別的音訊估計。
模型原生音軌全部保留。網站會提供兩個獨立勾選項，選擇是否額外產生 no_vocals.wav 或 no_guitar.wav；預設不勾，雙選時分別輸出兩個伴奏。
後端 separate／extra_exports 契約與網頁獨立勾選均已實作，真正的混音仍待遠端模型接入。

網站也會保存來源音訊及 manifest.json；manifest 是處理紀錄，包含模式、版本、檔案清單與驗證資訊，不需要匯入 DAW。
一次打包成 ZIP 可以方便下載，但仍只是裝著多個檔案的壓縮包；目前沒有實作 ZIP 匯出。

## 目前實際狀態

已完成的真實下載只有 source WebM 與 manifest，尚未執行模型。
示範 WAV 是合成測試音，不能當作真實歌曲分軌結果。
目前 API 已支援 separate 的原生類別與選填伴奏產物契約，示範仍為合成音；真實模型尚未接入。
模型在另一台電腦接入後，才會產生真正的分離音檔，並驗證時基、音質與 DAW 匯入結果。

## WAV 可以直接播放嗎？

本專案採 PCM WAV，是一般可直接播放的音訊檔，常見桌面播放器及現代瀏覽器可播放；不用先放入 DAW 或轉成 MP3。網站用 audio 播放器試聽，實際支援仍受編碼與瀏覽器影響。PCM WAV 通常未壓縮，同長度檔案會比常見有損 MP3／AAC 大。
